Supabase Database Connection Guide

This Spring Boot project is pre-configured with the official PostgreSQL driver for Supabase. By default, it runs with an in-memory H2 database so you can test immediately. When you are ready to connect to your Supabase project, follow these 3 simple steps:

1

Copy Connection Details from Supabase

Go to your Supabase Dashboard → Select your Project → Project Settings → Database → scroll to Connection string (URI or JDBC).

2

Update application.properties

Open src/main/resources/application.properties in this project and configure:

spring.datasource.url=jdbc:postgresql://aws-0-us-east-1.pooler.supabase.com:5432/postgres?sslmode=require
spring.datasource.username=postgres.YOUR_PROJECT_REF
spring.datasource.password=YOUR_DATABASE_PASSWORD
spring.jpa.database-platform=org.hibernate.dialect.PostgreSQLDialect
spring.jpa.hibernate.ddl-auto=update
3

Run Spring Boot Application

Hibernate will automatically create the tables (dim_time, dim_product, dim_store, fact_sales) and seed the initial data in your Supabase database!
